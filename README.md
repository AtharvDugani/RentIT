# RentIt – Peer-to-Peer Device Rental Application

RentIt is a web-based platform that allows people to rent, buy, and sell electronic devices. It connects people who need devices temporarily with owners who have devices they do not use regularly.

## Features

- User registration and login
- User profile management and KYC verification
- List devices for rent, sale, or both
- Search and filter devices by category, price, location, and availability
- Send rental requests and negotiate rental prices
- Owner approval of rental requests
- Buy and sell electronic devices
- Online payments and refundable security deposits
- Delivery, handover, and return management
- In-app wallet and refund management
- Ratings and reviews for users and devices
- Notifications and platform-based communication
- Dispute handling and customer support
- Admin dashboard for managing users, listings, and transactions

## Technology Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Django (Python)
- **Database:** MySQL
- **Version Control:** Git and GitHub
- **Development Tool:** Antigravity
